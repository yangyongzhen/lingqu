## 二、每轮做了什么

### 2026-10-28 · 骨架（0.1.0）

- 用 `cj-tauri create lingqu --template app` 生成骨架，`cj-tauri sync` 派生 desktop + ohos
- `src/main.cj`：`t2h:env` 环境体检八项；cjh 的 TCP 探测 + `launchHidden` 拉起（当时的精简版）
- `assets/ui/index.html`：七步导航 + 中栏工作区 + 右栏 Agent Dock（原生 HTML/CSS/JS，令牌与 ai-chat 同套）
- 文档：`docs/需求.md`、`docs/产品方案.md`、`docs/技术思路.md`、`docs/ui-mockup.html`

**踩坑（详见 `docs/开发环境.md`）**：缺 `libcjtbridge.dll`（退出码 0xC0000135）→ 缺 `WebView2Loader.dll`
→ 工作目录不是工程根（`资产未找到：ui/index.html`）。

### 2026-10-28 · 随包与启动脚本（0.1.1）

- `vendor/cjh/win-x64/`：内置 cjh 产物 + `SHA256SUMS`；`tools/vendor-cjh.ps1` 重灌
- `scripts/run-dev.ps1`：按框架 `run_win.bat` 口径配四段 PATH + 工作目录 + `LINGQU_CJH`
- **修 `.ps1` BOM 坑**：PS 5.1 按 GBK 读无 BOM 脚本 → 中文撑坏引号 → 报「数组索引表达式丢失或无效」
- **修 `.gitignore`**：模板 `*.dll` 把 vendor 的运行时 DLL 一起忽略（克隆后 HTTPS 全灭）
- 纠正 cjh 版本：实测 `/api/health` 回报 **1.6.1**

### 2026-10-29 · 引擎托管完整化 + 工程规范（0.2.0）

- `src/cjh_host.cj`：完整移植 ai-chat 的托管实现（详见 `CHANGELOG.md` 0.2.0 与 ADR D-003～D-008）
- `src/main.cj`：守护线程收尾 + `t2h:quit` + 后台自动 ensure + 日志落盘
- UI：三态展示 +「一键部署并启动」/「用指定路径启动」/「退出」
- **测试与门禁**：`src/tests/core_test.cj`（13 例）+ `scripts/test.ps1`（四道闸）
- **规范文档**：`AGENTS.md`、`CHANGELOG.md`、`docs/需求追踪.md`、`docs/设计决策记录.md`、本文件、`docs/会话交接.md`

**本轮踩坑**：① 加了 `LogPlugin` 却没声明 `log:path`/`log:write` → 被 `cj-tauri check` 三方比对拦下；
② `cjpm test` 报 `undefined symbol: cj_bridge_*` → 业务包 `cjpm.toml` 缺 `-lcjtbridge`；
③ 链接失败 `Permission denied` → 上一版窗口还开着占用 `main.exe`。

## 四、下一步（按优先级）

1. **`t2h:scan`（M1）** —— 五类清单 + 可迁移度评分 + 覆盖率分子分母。
   先在 `habit-tree` 上跑，用"评分是否与人工判断一致"验证扫描器抓对了特征。
   **扫描器做静态分析，不交给 agent**：评分要可复现可对比。
2. **UI 三态人工验一遍**（10 分钟）：部署按钮、关窗口后 `cjh.exe` 是否消失。
3. **`t2h:deps`（M2）** —— 依赖矩阵，先在 4 个本地样本上把"不可用 crate"清单跑出来。
4. **鸿蒙端首次 HAP 构建**（需要登录华为账号做签名）——越早遇到越好。

**不要做的事**：不要在规则库还没被真实样本验证前就大规模写规则；不要把可枚举的机械改造交给 LLM。
