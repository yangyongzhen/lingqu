**habit-tree 实测对照（本轮的核心证据）**

对迁移前的 Cargo.toml（main 分支）跑 dry-run，产物与真实迁移后的文件 diff：

- **功能性代码行全部一致**：crate-type、三处钉版、features 合并、OHOS target 段、

**这轮踩到的坑（已进 AGENTS §4）**

1. **行元素里塞 `\n` 破坏行模型**：ruleTauriPin 把注释与代码并进一个行元素，后续规则按行扫

2. **`spliceLines` 死循环 OOM**：`count=0 && i==at` 时 `i += 0` 后 `continue` 无限插入。
   单测只报 ERROR 不给栈——**直跑 `target/release/unittest_bin/lingqu.tests` 才拿到异常栈**。
3. `ArrayList` 没有 `insert`（只有 `add` 追加）——按下标插行要用重建实现。

**未做（如实标注）**：T4-3/4/5/8 留给 P4 第二刀；T4-7 按砍单顺序最后；
