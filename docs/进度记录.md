## 二、每轮做了什么

### 2026-10-30 · P1 对话通道接通（0.5.0）

- **装配 `WsPlugin`** + capabilities（`ws:connect/send/close`、`ws:frame/ws:state`、`ws:default`、`scopes.ws`）
- **页面 WS 通道**（对齐 cjnote 的跑通实现）：自动连、`ws:state` 为唯一判据、退避重连、
  帧分发（delta 节流累积 / tool_start / tool_result 认 `is_error` / done 认 `finish_reason` /
  approval_request / error / cancelled / history_messages / raw）、**帧解包先认 `p.type`**、
  `session_id` 接住后重连 `resume_session`
- **工具卡 + 审批卡**（倒计时与 `expires_in_ms` 同步，超时按拒绝收场）、错误按 `code` 给可执行提示、
  会话控制（＋新建 / ■中断）
- **自检扩展**：`wsState / frames / toolCards / approvals / lastFrameType / replyPreview`；
  `LINGQU_UI_PROBE=approval` 模式会发一条危险指令并**自动点拒绝**

**证据**：常规探针 `frames=2, last=done, replyPreview="收到"`；审批探针 `approvals=1` →
自动拒绝 → 回合继续到 `done`（`frames=268`）。四道闸全绿。

**踩坑**：cjh 默认宽松（无 `capability` 段＝所有工具放行），审批卡不会自己冒出来；
验证时需临时开 `capability.enabled=true + approval:["*:*"]`，**验完必须恢复**（密钥在 `auth.json`，不在 settings.json）。

### 2026-10-30 · 跨平台工程化 + 界面可自动验证（0.4.0）

- **门禁改成 bash 为准**：`scripts/test.sh`（跨平台一份）+ `test.bat`（Windows 委托 bash）；
  弃用 `.ps1`。顺带修掉「失败时只 grep FAILED/ERROR 而把真因藏掉」的门禁 bug
- **跨平台启动与初始化**：`run-dev.sh/.bat`、`setup.sh`（一键改本机绝对路径）
- **Linux 随包引擎**：`vendor/cjh/linux-x64/cjh` + Linux 侧 SHA256 校验；`.gitattributes` 管换行与可执行位
- **界面自检闭环**：新增 `t2h:ui_report`，页面回投版面指标 → 落 `.lingqu/ui-report.json` / `.log`；
  `LINGQU_UI_PROBE=1` 时自动跑「开设置 → 折叠 → 展开」序列
- **修掉一个真功能缺陷**：`t2h:cjh_models`/`cjh_settings`/`cjh_settings_save` 只写了 `match`
  分支却没 `app.register` → 页面 `command not registered`。**是界面自检抓出来的**
  （`cj-tauri check` 只查「已注册 ⊆ 已声明」）
- 新增 `Ctrl+,` 打开模型设置

**证据（本轮首次做到"没有视觉也能验版面"）**：

### 2026-10-29 · UI 门面重做 + 模型配置（0.3.0）

- **七屏填实**：按 `docs/ui-mockup.html` 把六个占位屏做成高保真示意（评分环 / 维度条 / 覆盖率 /

- **后端**：新增 `t2h:cjh_models` / `t2h:cjh_settings` / `t2h:cjh_settings_save`，走 cjh 的 REST

- 编译期修掉两处仓颉语法：`JsonKind` 不能 `==` 比（改 match）、`JsonBool.getValueOr` 不存在（改 `asBool().getValue()`）
