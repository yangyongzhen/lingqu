# 案例素材清单

> **用途**：把本机可参考的迁移样本、框架/引擎仓库、文档与文章集中登记，标明「每个素材能提取什么」。
> 服务于 `docs/实施路线图.md` 的 P2–P7：**规则库、错误指纹库、验证探针的语料都来自这里**。
>
> **引用纪律**（重要）：
> 1. 结论以**本地实测**为准；文章只作线索，不当判据。
> 2. 引用样本时写到 `仓库@commit:文件:行` 或 `docs/xxx.md §节`，能复核。
> 3. 素材有更新（分支/提交变了）时，本文件与对应规则库同批更新。

```bash
# 抽查某条结论落在哪（写规则 evidence 时用）
grep -rn "app_data_dir\|rfd::\|localStorage" <样本路径>/src-tauri/src <样本路径>/src
```
