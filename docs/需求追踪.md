## 五、维护规则

1. 新增功能 → 在本表登记（编号 + 状态 + 证据），再写代码。
2. 状态升级到 `已验证` 必须能指到**具体证据**（日志行 / 命令输出 / 截图 / 报告路径）。
3. 验收项（A1–A5）的任何变化都要同步 `docs/会话交接.md` 的「未完成」清单。
