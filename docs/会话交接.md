## 三、关键决策（别再翻案，要翻先看 ADR）

1. **外壳 = cj-tauri**（不是 Electron / 官方 Tauri / 纯 Web）——D-001
2. **cjh 走进程外 web 模式**（REST 8765 + WS）——D-002
3. **引擎生命周期六条语义**：健康检查 HTTP 200 / 复用优先 / 只收自己拉起的 / `launchHidden` / 只绑回环 / 拉起前先收自己上一只——D-003
4. **可执行二进制必须过 SHA256**，验不过绝不解包也不执行——D-004
5. **随包用已解包目录**，zip 只作兜底——D-005
6. **退出收尾用守护线程**（新形态 `AppSpec` 无 onExit 钩子）——D-006
7. **单测只测纯函数**，进程/网络/真机不造假绿——D-009
8. **脚本编码纪律**：`.ps1` 必须 UTF-8 BOM、`.bat` 必须纯 ASCII、禁止 shell 回写源码——D-010

## 五、换机器怎么接

### 1) 装依赖

| 组件 | 说明 |
|---|---|
| 仓颉 SDK 1.2.0 | `cjpm` / `cjc` 在 PATH，或设 `CANGJIE_HOME` |
| stdx（桌面版） | 解压后把 `CANGJIE_STDX` 指到 `<stdx>/<三元组>/dynamic/stdx` |
| cj-tauri 框架仓 | 克隆后放在任意位置；`native/` 里要有 `libcjtbridge.dll` 与 `webview2/WebView2Loader.dll` |
| DevEco Studio + OHOS SDK | 只在编鸿蒙 HAP 时需要 |
| Windows | 还需 WebView2 Runtime（Win11 自带） |

### 2) 改三处本机绝对路径

- `cjpm.toml`：`cjTauri = { path = "..." }` 与两处 `link-option` 里的 `-L<native>`
- `cj-tauri.toml`：无路径，但改完要重跑 sync
- `scripts/run-dev.ps1` 与 `scripts/test.ps1` 顶部「配置区」：`CangjieHome` / `Stdx` / `CjTauriRoot`

### 3) 三条命令接上

```powershell
cd <repo>
.\scripts\test.ps1 -Sync      # 派生骨架 + 过四道闸（第一次必跑）
.\scripts\run-dev.ps1 -Build  # 编译并起窗口（引擎会自动拉起）
```

### 4) 接上的判据

- `.\scripts\test.ps1` 全绿
- 窗口标题 `灵渠迁移台 · Lingqu`；顶栏 cjh 标记从「可拉起」变「已连接 :8765」
- `%LOCALAPPDATA%\cj-tauri\logs\lingqu.log` 里有 `[lingqu] AI 引擎就绪：127.0.0.1:8765`
- 关窗口后任务管理器里没有 `cjh.exe`

> 卡住先读 `docs/开发环境.md` 的「踩过的坑（按报错原文索引）」——11 条里大概率有一条正好命中。

## 六、常用命令速查

```bash
# 门禁（交付前必跑；Windows 用 scripts\test.bat 同样参数）
./scripts/test.sh -s          # 派生骨架 + 四道闸
./scripts/test.sh -q          # 只跑 build + test（改业务代码的快速回路）
./scripts/test.sh -c          # 清增量缓存再跑（业务包公开接口变更后）

# 开发
./scripts/run-dev.sh -b       # 编译 + 起窗口（AI 引擎自动拉起）
./scripts/setup.sh            # 换机器时对齐 cjpm.toml 里的本机绝对路径

# 界面自检（无视觉也能验版面）
LINGQU_UI_PROBE=1 ./scripts/run-dev.sh
cat .lingqu/ui-report.log     # 版面指标序列

# 骨架
<框架>/cli/target/release/bin/main.exe sync [desktop|ohos]
<框架>/cli/target/release/bin/main.exe check      # 三方比对 + 漂移

# 引擎
curl http://127.0.0.1:8765/api/health
curl http://127.0.0.1:8765/api/models

# 更新随包 cjh（之后记得同步 src/cjh_host.cj 里的 SHA256 常量）
./tools/vendor-cjh.sh --source <cjh 产物目录> --platform win-x64
./tools/vendor-cjh.sh --source <cjh 产物目录> --platform linux-x64
```
