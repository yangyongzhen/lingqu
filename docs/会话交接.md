## 三、关键决策（别再翻案，要翻先看 ADR）

1. **外壳 = cj-tauri**（不是 Electron / 官方 Tauri / 纯 Web）——D-001
2. **cjh 走进程外 web 模式**（REST + WS `127.0.0.1:8765`）——D-002
3. **引擎生命周期六条语义**：健康检查 HTTP 200 / 复用优先 / 只收自己拉起的 / `launchHidden` / 只绑回环 / 拉起前先收自己上一只——D-003
4. **可执行二进制必须过 SHA256**，验不过绝不解包也不执行——D-004
5. **随包用已解包目录**，zip 只作兜底——D-005
6. **退出收尾用守护线程**（新形态 `AppSpec` 无 onExit 钩子）——D-006
7. **单测只测纯函数**，进程/网络/真机不造假绿——D-009
8. **脚本 bash 为准、`*.bat` 只做委托、不再新增 `.ps1`**——D-012
9. **界面必须可自动断言**（`t2h:ui_report` + 探针），不靠肉眼看截图——AGENTS §1.6

## 五、换机器怎么接

### 1) 装依赖

| 组件 | 说明 |
|---|---|
| 仓颉 SDK 1.2.0 | `cjpm` / `cjc` 在 PATH，或设 `CANGJIE_HOME` |
| stdx（桌面版） | `CANGJIE_STDX` = `<stdx>/<三元组>/dynamic/stdx` |
| cj-tauri 框架仓 | `native/` 里要有 `libcjtbridge.dll/.so` 与（Windows）`webview2/WebView2Loader.dll` |
| Git Bash（Windows） | 脚本本体是 bash；`*.bat` 会自动找 |
| DevEco + OHOS SDK | 只在编鸿蒙 HAP 时需要 |
| cjh | 仓内 `vendor/cjh/` 已随包（win + linux），无需另装 |

### 2) 三条命令接上

```bash
cd <repo>
./scripts/setup.sh          # 对齐 cjpm.toml 里的本机绝对路径（框架 path + 两处 -L<native>）
./scripts/test.sh -s        # 派生骨架 + 四道闸
./scripts/run-dev.sh -b     # 编译并起窗口（引擎会自动拉起）
```

Windows 把 `./scripts/xxx.sh` 换成 `scripts\xxx.bat`（同样参数）。

### 3) 接上的判据

- `./scripts/test.sh -s` 四道闸全绿
- 窗口标题 `灵渠迁移台 · Lingqu`；右栏状态胶囊显示「已连接」
- 在输入框发一句话 → 有流式回复（自检探针会自动发一句，`replyPreview` 非空即可）
- 关窗口后任务管理器里没有 `cjh.exe`

> 卡住先读 `docs/开发环境.md` 的「踩过的坑（按报错原文索引）」与 `AGENTS.md` §4 的 19 条。

## 六、常用命令速查

```bash
# 门禁（交付前必跑；Windows 用 scripts\test.bat 同样参数）
./scripts/test.sh -s          # 派生骨架 + 四道闸
./scripts/test.sh -q          # 只跑 build + test（改业务代码的快速回路）
./scripts/test.sh -c          # 清增量缓存再跑（业务包公开接口变更后）

# 开发
./scripts/run-dev.sh -b       # 编译 + 起窗口（AI 引擎自动拉起）
./scripts/setup.sh            # 换机器时对齐 cjpm.toml 里的本机绝对路径

# 界面 + 通道自检（无视觉也能验）
LINGQU_UI_PROBE=1 ./scripts/run-dev.sh          # 版面 + 折叠 + 真实发问
LINGQU_UI_PROBE=approval ./scripts/run-dev.sh   # 审批卡（需先把 cjh 临时置严格模式）
cat .lingqu/ui-report.log                        # 每次上报一行 JSON

# 骨架
<框架>/cli/target/release/bin/main.exe sync [desktop|ohos]
<框架>/cli/target/release/bin/main.exe check      # 三方比对 + 漂移

# 引擎
curl http://127.0.0.1:8765/api/health
curl http://127.0.0.1:8765/api/models

# 更新随包 cjh（之后记得同步 src/cjh_host.cj 里的 SHA256 常量）
./tools/vendor-cjh.sh --source <cjh 产物目录> --platform win-x64
./tools/vendor-cjh.sh --source <cjh 产物目录> --platform linux-x64
```

## 七、接手第一小时建议

1. 跑 `./scripts/test.sh -s`，确认四道闸全绿（不绿先修环境，别看代码）。
2. 跑 `LINGQU_UI_PROBE=1 ./scripts/run-dev.sh`，看 `.lingqu/ui-report.log`——
   一眼就能确认"窗口/布局/通道"三件事都是好的。
3. 读 `docs/实施路线图.md` 的 P2 一节，**先把覆盖率口径定下来再动手写扫描器**
   （"每项都有处置结论"里的"项"到底是清单条目还是文件行，直接决定扫描器抓什么）。
