# 单文件包里**编不进静态库**的随包文件（一行一个，相对仓根）
#
# cjh 是独立可执行程序 + 4 个按名字加载的运行时 DLL，既不能静态链接、也不在 PE 导入表里，
# 只能作为 PE 资源（RT_RCDATA）跟着 exe 走，运行期由 C 桥取出来写盘
# （`cj-tauri` 的 `extractEmbeddedAssets` → `%LOCALAPPDATA%\lingqu\cjh`）。
# 清单里的路径必须真实存在，否则打包脚本直接失败（别让"少一个 DLL"变成运行期才炸）。
#
# ⚠ 这份清单必须与 `src/cjh_host.cj` 的 `CJH_VENDOR_FILES`（5 项）**逐项对齐**：
#   释放完之后 `cjhVendorVerified()` 会逐个点名核对 SHA256，少一件就是"校验不过 ⇒ 引擎不启用"
#   （§4-55：释放 ≠ 可用）。0.39.61 随包引擎升 1.6.5 时新增了 libboundscheck.dll，
#   这里当时漏了 —— 后果正是"单文件包里 AI 引擎缺失"，本次补上。
